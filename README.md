# NITRO AI
رابط دستیار فارسی با چیدمان راست‌چین، پایگاه دانش آفلاین، جست‌وجوی منبع‌محور و ابزارهای محلی.

## قابلیت‌ها
- چت جدید، تاریخچه گفتگو و ذخیره محلی
- پایگاه داده آفلاین در پوشه data/offline
- واژه‌نامه منتخب فارسی↔انگلیسی با جست‌وجوی عبارت کامل و کلمه‌به‌کلمه
- دانش منتخب SCP و کریپی‌پاستا به فارسی و انگلیسی
- جست‌وجوی آنلاین یک‌منبعی در Wikipedia با خلاصه متن همان صفحه
- سه سطح رابطی برای تنظیم سقف طول پاسخ در موتور متصل‌شده (کند، متوسط و قوی)
- تصویرساز محلی Canvas برای شکل‌ها و صحنه‌های ساده؛ هنوز مدل مولد تصویر نیست
- کتابخانه تصاویر، پروژه‌های محلی، اکسپلور، انتخاب مدل و پلن نمایشی
- Service Worker برای ذخیره فایل‌های اصلی و بسته دانش آفلاین پس از اولین بازدید آنلاین

## پوشه داده آفلاین
در مسیر data/offline این فایل‌ها قرار دارند:
- dictionary.fa-en.json
- dictionary.en-fa.json
- scp-lore.fa-en.json
- README.md (راهنمای بارگذاری، جست‌وجوی کلمه‌به‌کلمه و افزودن مدخل)

## اجرای پروژه
از GitHub Pages یا یک وب‌سرور محلی اجرا کن. برای استفاده از Service Worker و حالت آفلاین، سایت باید از HTTPS یا localhost باز شود. یک بار با اینترنت صفحه را باز کن تا Service Worker فایل‌های داده را در Cache مرورگر ذخیره کند؛ پس از آن بسته دانش و پوسته برنامه می‌توانند بدون اینترنت در دسترس باشند. فایل HTML را مستقیماً با file:// باز نکن.

## محدودیت‌های صادقانه
- واژه‌نامه فعلی شامل ۲۶۹ مدخل منتخب در هر جهت است، نه تمام واژگان زبان فارسی یا انگلیسی. برای پوشش وسیع‌تر باید مجموعه داده بزرگ‌تر و دارای مجوز مناسب به مخزن اضافه شود.
- ترجمه کلمه‌به‌کلمه برای عبارت‌های پیچیده یا جمله‌های طولانی جای ترجمه بافت‌محور را نمی‌گیرد.
- دانش SCP/کریپی‌پاستا محدود به پرونده‌های منتخب است. این آثار تخیلی‌اند و به‌عنوان واقعیت تأییدشده معرفی نمی‌شوند.
- جست‌وجوی آنلاین از Wikipedia API استفاده می‌کند و یک نتیجه را با خلاصه استخراج‌شده از متن منبع نشان می‌دهد.
- سه حالت فکر فعلاً تنظیم نمایشی در رابط‌اند و به سه موتور استدلال متفاوت وصل نیستند.
- تصویرساز، طرح‌های گرافیکی را در Canvas مرورگر می‌سازد و مدل مولد تصویر هوش مصنوعی نیست.
- مدل‌های Image و Model در این نسخه هنوز ابزارهای گرافیکی محلی‌اند. گفتگوها و تصاویر در مرورگر کاربر ذخیره می‌شوند.

## NITRO Core — موتور زبانی خودمیزبان
نسخه 0.1 یک زیرساخت واقعی برای اجرای مدل زبانی روی سروری تحت کنترل پروژه اضافه می‌کند:
- `backend/app.py`: درگاه API با محدودیت اولیه درخواست‌ها
- `docker-compose.yml`: اجرای llama.cpp و درگاه NITRO با Docker
- مدل شروع: Qwen2.5-1.5B-Instruct GGUF با Q4_K_M
- `config.js`: محل تنظیم نشانی عمومی HTTPS موتور برای اتصال GitHub Pages
- `NITRO-ROADMAP.md`: نقشه راه استقلال پروژه

برای راه‌اندازی، راهنمای [backend/README.md](backend/README.md) را بخوان. تا وقتی سرور ابری نصب و `API_URL` تنظیم نشده باشد، چت آنلاین به موتور واقعی وصل نیست. این مدل متن‌باز خودمیزبان است؛ هنوز مدلی نیست که از صفر توسط NITRO آموزش داده شده باشد. کیفیت مدل 1.5B محدود است و برای استفاده هم‌زمان کاربران بیشتر، سرور قوی‌تر و کنترل سهمیه لازم می‌شود.
