# NITRO AI
رابط گفت‌وگوی فارسی با طراحی راست‌چین و تجربه کاربری الهام‌گرفته از دستیارهای مدرن.

## قابلیت‌ها
- چت جدید، تاریخچه و ذخیره محلی گفتگوها
- چیدمان دسکتاپ با ستون گفتگو در سمت راست؛ واکنش‌گرا برای موبایل
- پایگاه دانش اولیه فارسی/انگلیسی درباره SCP و کریپی‌پاستا
- اطلاعات منتخب درباره SCP-173، 049، 682، 096، 999، 106، 035، 087، 3008 و پیشنهادهای SCP-001
- موضوعات کریپی‌پاستا مانند Slender Man، Backrooms، The Rake، Candle Cove، Ted the Caver و Polybius
- جست‌وجوی ویکی‌پدیای فارسی و در صورت نبود نتیجه انگلیسی؛ نمایش یک منبع و خلاصه‌ای کوتاه از متن همان منبع
- ساخت تصویر ساده مکعبی با Canvas در مرورگر (چمن، سنگ، الماس، چوب، آجر، شن و خاک)
- کتابخانه تصاویر، پروژه‌ها، اکسپلور، حالت فکرکردن و انتخاب مدل نمایشی

## اجرا
پروژه استاتیک است و از GitHub Pages قابل اجراست. برای جست‌وجوی وب، اتصال اینترنت لازم است.

## محدودیت‌ها
این پروژه یک دستیار مستقل هم‌سطح ChatGPT نیست و هنوز به مدل زبانی ابری وصل نشده است. پاسخ‌های SCP/کریپی‌پاستا از یک پایگاه دانش کوچک و ویرایش‌شده در کد می‌آیند؛ برای موارد ناشناخته باید جست‌وجو را فعال کرد. جست‌وجوی فعلی از Wikipedia API استفاده می‌کند و فقط یک نتیجه را همراه خلاصه استخراج‌شده از متن منبع نشان می‌دهد؛ این خلاصه‌سازی توسط مدل زبانی انجام نمی‌شود. تصویرساز فعلی یک مکعب گرافیکی ساده را در مرورگر رسم می‌کند و مدل مولد تصویر نیست. پلن‌ها، مدل‌ها، پلاگین‌ها و فکرکردن فعلاً نمایشی‌اند. داده‌ها در localStorage مرورگر ذخیره می‌شوند.

## نکته محتوایی
SCP و کریپی‌پاستا در این پروژه به‌عنوان داستان‌های تخیلی و افسانه‌های اینترنتی معرفی می‌شوند، نه واقعیت اثبات‌شده. برای جزئیات هر پرونده SCP، پیوند مقاله اصلی در SCP Wiki ارائه می‌شود.
