# NITRO AI
رابط فارسی دستیار هوشمند با چیدمان الهام‌گرفته از تجربه چت‌بات‌های مدرن.

## امکانات فعلی
- رابط راست‌چین و واکنش‌گرا
- چت جدید، تاریخچه گفتگو و ذخیره محلی
- انتخاب مدل نمایشی، حالت فکرکردن و پلن‌های نمایشی Free / Plus
- صفحات اکسپلور، پروژه‌ها و کتابخانه تصاویر
- جست‌وجوی عمومی از طریق Wikipedia OpenSearch API و نمایش پیوند منابع
- پاسخ‌های پایه محلی به فارسی

## اجرای پروژه
این پروژه استاتیک است. برای اجرا می‌توانی GitHub Pages را باز کنی یا فایل index.html را در مرورگر اجرا کنی. جست‌وجوی آنلاین به اینترنت نیاز دارد.

## محدودیت‌های مهم
این پروژه کپی نرم‌افزار یا سرویس ChatGPT نیست و به حساب‌ها، مدل‌ها، گفتگوها، پلاگین‌ها یا اشتراک‌های OpenAI دسترسی ندارد. پلن‌ها، مدل‌ها و صفحات برخی ابزارها صرفاً نمایشی‌اند. جست‌وجوی فعال فعلی از Wikipedia OpenSearch استفاده می‌کند و موتور پاسخ‌گویی کامل هنوز به API مدل زبانی متصل نشده است. برای اتصال امن مدل و ارائه قابلیت‌های واقعی چندکاربره، به backend و کلید API نگهداری‌شده در سمت سرور نیاز است. اطلاعات گفتگوها و تصاویر در localStorage همان مرورگر ذخیره می‌شوند.
