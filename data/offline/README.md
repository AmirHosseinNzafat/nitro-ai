# NITRO AI — Offline Knowledge Pack

این پوشه پایگاه داده آفلاین نیترو است. فایل‌ها JSON با کدگذاری UTF-8 هستند.

## فایل‌ها
- `dictionary.fa-en.json`: واژه‌نامه فارسی به انگلیسی.
- `dictionary.en-fa.json`: واژه‌نامه انگلیسی به فارسی.
- `scp-lore.fa-en.json`: پرونده‌های منتخب SCP و کریپی‌پاستا با متن فارسی، انگلیسی و منبع.

## بارگذاری در JavaScript
```js
const [faEn, enFa, lore] = await Promise.all([
  fetch('./data/offline/dictionary.fa-en.json').then(r => r.json()),
  fetch('./data/offline/dictionary.en-fa.json').then(r => r.json()),
  fetch('./data/offline/scp-lore.fa-en.json').then(r => r.json())
]);
```

## جست‌وجوی کلمه‌به‌کلمه
۱. ابتدا عبارت کامل را جست‌وجو کن تا اصطلاح‌هایی مثل «عشق ابدی» ترجمه یکپارچه بگیرند.
۲. اگر عبارت کامل پیدا نشد، متن را به واژه‌ها تقسیم کن.
۳. هر واژه را در هر دو دیکشنری بررسی کن و معادل را نمایش بده.
۴. نتیجه محلی را با برچسب «واژه‌نامه آفلاین» مشخص کن.
۵. اگر داده‌ای پیدا نشد، جست‌وجوی آنلاین را انجام بده؛ منبع را فقط وقتی نمایش بده که واقعاً دریافت شده باشد.

## پرونده‌های SCP و کریپی‌پاستا
با id، name_fa یا name_en در آرایه scp جست‌وجو کن. متن را با توجه به زبان انتخاب کن و URL اصلی را به‌عنوان منبع نشان بده. کریپی‌پاستا در آرایه creepypasta قرار دارد.

## افزودن واژه
یک شیء با ساختار `{"word":"واژه","translation":"معادل"}` به entries اضافه کن. برای حفظ جست‌وجوی دوطرفه، نسخه معکوس را نیز به فایل زبان مقابل اضافه کن.

## محدودیت
این مجموعه یک واژه‌نامه منتخب و قابل گسترش است، نه کل دیکشنری فارسی یا انگلیسی. زبان‌ها اصطلاحات، صرف‌ها، هم‌معنی‌ها و معنی‌های وابسته به بافت بسیار زیادی دارند. برای ترجمه دقیق جمله‌های طولانی به موتور ترجمه یا مدل زبانی نیاز است.
